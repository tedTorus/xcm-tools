Fixes #2672

### Description
`isBridgedSystemAsset` previously only checked that a location had `parents === 2` and contained a `GlobalConsensus` junction. It did not verify the length or exact structure of the interior, allowing any bridged asset (like a memecoin with an `X2` or `X3` interior) to masquerade as a system asset if it shared the same global consensus.

### Solution
Added a strict `'X1' in asset.location.interior` check. True bridged system assets (like the relay chain's native token) only have a single `GlobalConsensus` junction (`X1`). This prevents foreign assets and memecoins from bypassing bridge validation and being erroneously burned.
