Fixes #2675

### Description
`getLocationTokenId` previously only checked if `location.interior === 'Here'` to identify a native token, completely ignoring `location.parents`. In XCM, `{parents: 1, interior: Here}` represents the relay chain's native token, not the parachain's. This caused relay token fees to be mislabeled as the parachain's native token (e.g., DOT mislabeled as ACA).

### Solution
Added a strict `location.parents === 0` check to the native token branch in both PJS and PAPI implementations. This ensures only the actual native token of the current chain is resolved, preventing cross-asset fee pollution.
