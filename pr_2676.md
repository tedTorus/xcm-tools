Fixes #2676

### Description
`PolkadotJsApi.getDryRunXcm` previously attempted to read the weight directly from `executionResult.used`. However, the underlying polkadot.js API returns the used weight nested under `executionResult.complete.used`. This caused the destination `weight` to always evaluate to `undefined`.

### Solution
Updated the property accessor to safely check `executionResult.complete?.used` before falling back to `executionResult.used`. This ensures the weight is correctly extracted when the dry-run successfully computes it.
